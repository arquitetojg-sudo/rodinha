# Primeiros Acordes

App (PWA) para aprender violão do zero: conhecer o instrumento, afinar, primeiros acordes,
batidas, tocar junto com clique e batida sintetizada, e descobrir o capotraste que deixa
uma música fácil. Funciona offline; o progresso fica salvo no aparelho.

Publicado em https://arquitetojg-sudo.github.io/primeiros-acordes/

## Comandos
`npm install` · `npm run dev` · `npm test` · `npm run typecheck` · `npm run build` · `npm run preview`
